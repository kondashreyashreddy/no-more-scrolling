# No More Scrolling - Advice On How To Reduce Doomscrolling
## Program
In this day and age, doomscrolling has become a major problem in our society. This program is an informational app designed to provide informations on the negative impact doomscrolling has on us and the human mental state. There is also a quiz portion of the program that users complete to refine their understanding on the topic.
## Program Type
Created in Code.org's App Lab using block modules.
